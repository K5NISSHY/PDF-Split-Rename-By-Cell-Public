PDF 1ページ分割・セル別リネームツール（Windows 11）
====================================================

機能
----
PDFを1ページずつに分割し、Excelで指定した開始セルから下方向に1行ずつ読み込んだ値を各PDFのファイル名にします。ファイル名に連番は付けません。

例：開始セルがA1、PDFが3ページの場合
A1 = あいう → あいう.pdf
A2 = かきく → かきく.pdf
A3 = さしす → さしす.pdf

フォルダー構成
--------------
pdf_splitter_by_cell.py  分割ツール本体
起動.bat                 ダブルクリックで起動するファイル
README.md                説明書（Markdown版）
README_使い方.txt        この説明書
test_pdf_splitter_by_cell.py  自動テスト

必要なもの
----------
- Windows 11
- Python 3.10以降
- Excelブック（.xlsx または .xlsm）

Pythonとライブラリの準備
------------------------
起動.batが「Python was not found」と表示した場合は、Pythonが未インストールかPATHに登録されていません。
https://www.python.org/downloads/windows/ からPython 3をインストールしてください。
インストール時に「Add python.exe to PATH」を有効にします。

起動.batは、まず「py -3」、使えない場合は「python」でPythonを探します。
起動時にpypdfとopenpyxlがあるかを確認し、不足していれば自動でインストールします。
初回のインストール時にはインターネット接続が必要です。

- pypdf: PDFの読み込みと各ページの書き出し
- openpyxl: Excelブックからセル値を読み込み
- tkinter: GUI（Pythonに付属する標準ライブラリ）

手動でインストールする場合は、コマンドプロンプトで次を実行します。

  py -3 -m pip install --user pypdf openpyxl

「py」が使えない場合：

  python -m pip install --user pypdf openpyxl

使い方
------
1. 起動.batをダブルクリックします。
2. 「分割するPDF」の「参照...」でPDFを選びます。
3. 「Excelファイル」の「参照...」でExcelブックを選びます。
4. シートを選び、「開始セル」に先頭セル（例: A1、B3）を入力します。
5. 出力先フォルダーを選び、「分割を実行」を押します。

PDFの1ページ目には開始セル、2ページ目にはその1行下、以降も同じ列を1行ずつ下にたどったセルを対応させます。
PDFのページ数分すべてのセルに値を入力してください。空欄がある場合は処理を中止します。

数式セル
--------
数式自体は計算せず、Excelがブックに保存した計算結果を使います。
保存済みの計算結果がない、または空の場合はエラーになります。
その場合はExcelでブックを開き、数式を再計算して保存してから、もう一度実行してください。

事前検査と安全性
----------------
- ファイル名に使えない文字（\ / : * ? " < > |）、制御文字、末尾の空白・ピリオド、Windowsの予約名は拒否します。
- 同じ名前になるセル値が複数ある場合は、上書きを避けるため処理を中止します。
- 出力予定のファイルがすでにある場合は、上書きせず処理を中止します。
- すべてのページを一時フォルダーに出力してから保存先へ移動します。保存に失敗した場合、作成途中のファイルを削除して後片付けします。
- 元PDFとExcelブックは変更しません。

自動テスト
----------
コマンドプロンプトでツールのフォルダーに移動し、次を実行します。

  python -m unittest -v
