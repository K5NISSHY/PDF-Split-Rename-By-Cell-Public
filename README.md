# PDF-Split-Rename-By-Cell

PDFを1ページずつに分割し、Excelで指定した開始セルから下方向へ読み込んだ値を、各ページのPDFファイル名にする Windows 11 向けツールです。ファイル名に連番は付けません。

## 動作例

開始セルが `A1` で、PDFが3ページの場合:

| ページ | Excelのセル | セルの値 | 出力ファイル |
|---:|---|---|---|
| 1 | A1 | あいう | あいう.pdf |
| 2 | A2 | かきく | かきく.pdf |
| 3 | A3 | さしす | さしす.pdf |



## サンプルファイル

`samples/` フォルダーに、動作を試すためのExcelブックと3ページのダミーPDFを入れています。Excelの `Sheet1` の `A1:A3` に「 あいう」「かきく」「さしす 」の名前が入っています（前後の空白はありません）。この2つのファイルを選び、シートを `Sheet1`、開始セルを `A1` にすると、次の3ファイルが作成されます。

- `あいう.pdf`
- `かきく.pdf`
- `さしす.pdf`

個人情報や実際の書類は含まれていません。まずはサンプルで画面操作を確認してから、手元のPDFとExcelでお試しください。

## 使用しているライブラリ

- `pypdf` はPDFを開いてページを読み取り、1ページずつ別ファイルに保存するためのライブラリです。
- `openpyxl` はExcelブックを開き、指定したセルに入力された値を読み取るためのライブラリです。Excelの数式を計算する機能はありません。数式を使う場合は、Excelで計算結果を保存してから実行してください。
- `tkinter` はファイル選択画面などを作るためのGUIライブラリです。Pythonに付属しているため、通常は別途インストールする必要がありません。

`起動.bat` は不足している `pypdf` と `openpyxl` を起動時にインストールします。初回のインストールにはインターネット接続が必要です。

## 必要なもの

- Windows 11
- Python 3.10 以降
- Excelブック（`.xlsx` または `.xlsm`）

`起動.bat` は `py -3`、利用できない場合は `python` でPythonを探します。起動時に `pypdf` と `openpyxl` が利用できるか確認し、不足していれば `pip install --user pypdf openpyxl` で自動インストールします。初回のインストール時にはインターネット接続が必要です。

- `pypdf`: PDFの読み込みと1ページごとの書き出し
- `openpyxl`: Excelブックからセル値を読み込み
- `tkinter`: GUI（Pythonに付属する標準ライブラリ）

## 使い方

1. `起動.bat` をダブルクリックします。
2. 「分割するPDF」でPDFを選びます。
3. 「Excelファイル」でExcelブックを選び、シートを指定します。
4. 「開始セル」に値を読む先頭セル（例: `A1`、`B3`）を入力します。
5. 「出力先フォルダー」を選び、「分割を実行」を押します。

PDFの1ページ目には開始セル、2ページ目にはその1行下、以降も同じ列を1行ずつ下にたどったセルを対応させます。PDFのページ数分すべてのセルに有効な値が必要です。

## 数式セル

数式自体は計算しません。数式セルは、Excelがブックに保存した計算結果をファイル名に使います。保存済みの計算結果がない、または空の場合はエラーを表示します。その場合はExcelでブックを開き、数式を再計算して保存してから実行してください。

## 事前検査と安全性

- PDF、Excel、シート、開始セル、出力先を実行前に確認します。
- 空欄、ファイル名に使えない文字、Windowsの予約名、同じ名前になるセル値を検出した場合は、処理を始めずエラーを表示します。
- 出力予定のファイルがすでに存在する場合は、上書きせず処理を中止します。
- 全ページを一時フォルダーに書き出してから出力先に移動します。保存に失敗した場合は、作成途中の出力を削除して後片付けします。
- 元のPDFとExcelブックは変更しません。
